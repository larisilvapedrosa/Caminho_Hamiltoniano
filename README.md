# Implementação do Algoritmo para Caminho Hamiltoniano em Python  

## Descrição do Projeto  
Este projeto implementa um algoritmo em Python para encontrar um Caminho Hamiltoniano em um grafo orientado ou não orientado. Um Caminho Hamiltoniano é um caminho que visita cada vértice exatamente uma vez.  

A implementação inclui:  
- Verificação da existência de um Caminho Hamiltoniano.  
- Retorno do caminho, caso exista.  
- Visualização do grafo e do Caminho Hamiltoniano (opcional).  

## Como Executar o Projeto  

### Pré-requisitos  
1. Ter o Python 3.8 ou superior instalado.  
2. Instale as bibliotecas necessárias:  
    ```bash  
    pip install networkx matplotlib  
    ```  

### Passos para Execução  
1. Clone o repositório:  
    ```bash  
    git clone <link>  
    cd <nome>  
    ```  
2. Execute o arquivo principal:  
    ```bash  
    python main.py
